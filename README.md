# Portafolio Jonathan Veloz - V6

## Cambios principales
- Hero full-width corregido, sin cortes laterales.
- Fondo minimalista más limpio y mejor distribuido.
- Interfaz general más dinámica.
- Tarjetas de proyectos con preview tipo browser.
- Fallback triple para previews:
  1. WordPress MShots
  2. thum.io
  3. s-shot
- Si los tres fallan, se mantiene una portada gráfica del proyecto.
- Se mantiene la sección "Mi participación".
- Se mantiene la tarjeta de tipos de sitios:
  - Landing pages
  - Webs informativas
  - Catálogos web
  - E-commerce

## Archivos
- index.html
- css/style.css
- js/projects.js
- js/main.js

## Abrir
Abrir la carpeta en Visual Studio Code y ejecutar index.html con Live Server.
